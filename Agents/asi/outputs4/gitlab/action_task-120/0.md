## Reusable Functions
```python
def search_repository(search_box_id: str | int, repo_name: str):
    """Search for a repository using the search box.
    
    Args:
        search_box_id: The ID of the search box element
        repo_name: The name of the repository to search for
        
    Returns:
        None
        
    Examples:
        search_repository('143', 'awesome-python')
        search_repository('143', 'python')
    """
    click(search_box_id)
    fill(search_box_id, repo_name)
    keyboard_press('Enter')
```

```python
def navigate_to_projects(projects_button_id: str | int):
    """Navigate to the projects list page.
    
    Args:
        projects_button_id: The ID of the Projects button
        
    Returns:
        None
        
    Examples:
        navigate_to_projects('58')
    """
    click(projects_button_id)
    click(projects_button_id)  # Second click to ensure navigation
```
