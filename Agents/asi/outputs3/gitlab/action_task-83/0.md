## Reusable Functions
```python
def navigate_to_profile_settings(profile_id: str, settings_id: str):
    """Navigate from the homepage to the profile settings page.
    
    Args:
        profile_id: The ID of the user profile link/button
        settings_id: The ID of the Settings link in the profile dropdown
        
    Returns:
        None
        
    Examples:
        navigate_to_profile_settings('186', '202')
    """
    click(profile_id)  # Click user profile link
    click(settings_id)  # Click Settings link in dropdown
```

```python
def update_profile_url(url_field_id: str, new_url: str, save_button_id: str):
    """Update the website URL in profile settings and save changes.
    
    Args:
        url_field_id: The ID of the website URL input field
        new_url: The new URL to set as homepage
        save_button_id: The ID of the save/update button
        
    Returns:
        None
        
    Examples:
        update_profile_url('481', 'byteblaze.github.io', '512')
    """
    fill(url_field_id, new_url)  # Fill the URL field with new URL
    click(save_button_id)  # Click save/update button
```
