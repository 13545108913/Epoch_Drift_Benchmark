## Reusable Functions
```python
def star_repository(repo_link_id: str):
    """Navigate to a repository page and star it.
    
    Args:
        repo_link_id: The ID of the repository link to click
        
    Returns:
        None
        
    Examples:
        star_repository('496')
        star_repository('564')
    """
    click(repo_link_id)  # Click repository link to navigate to its page
    click('495')  # Click the star button on repository page
    go_back()  # Navigate back to main projects page
```

```python
def check_and_star_repositories(repo_ids: list[str]):
    """Check and star multiple repositories in sequence.
    
    Args:
        repo_ids: List of repository link IDs to star
        
    Returns:
        None
        
    Examples:
        check_and_star_repositories(['496', '564', '663'])
    """
    for repo_id in repo_ids:
        click(repo_id)  # Click repository link to navigate to its page
        click('495')  # Click the star button on repository page
        go_back()  # Navigate back to main projects page
```
