## Reusable Functions
```python
def navigate_to_issues(repo_link_id: str):
    """Navigate to the issues page of a repository.
    
    Args:
        repo_link_id: The ID of the repository link to click
        
    Returns:
        None
        
    Examples:
        navigate_to_issues('759')
    """
    click(repo_link_id)  # Click repository link
    click('283')  # Click Issues tab
```

```python
def create_issue(title: str, description: str):
    """Create a new issue with title and description.
    
    Args:
        title: The issue title text
        description: The issue description text
        
    Returns:
        None
        
    Examples:

    """
```
