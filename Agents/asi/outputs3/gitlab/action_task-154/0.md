## Reusable Functions
```python
def navigate_to_issue(issues_link_id: str, issue_link_id: str):
    """Navigate to a specific issue page from the main issues section.
    
    Args:
        issues_link_id: The ID of the issues section link
        issue_link_id: The ID of the specific issue link
        
    Returns:
        None
        
    Examples:
        navigate_to_issue('161', '566')
    """
    click(issues_link_id)  # Click on issues section
    click(issue_link_id)   # Click on specific issue
```

```python
def assign_issue_to_user(edit_assignee_id: str, assignee_option_id: str, user_name: str):
    """Assign an issue to a specific user by editing the assignee field.
    
    Args:
        edit_assignee_id: The ID of the edit assignee button
        assignee_option_id: The ID of the assignee option in dropdown
        user_name: The name of the user to assign to
        
    Returns:
        None
        
    Examples:
        assign_issue_to_user('789', '1061', 'primer')
    """
    click(edit_assignee_id)     # Click edit assignee button
    click(assignee_option_id)   # Select assignee from dropdown
```
