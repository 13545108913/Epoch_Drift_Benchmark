## Reusable Functions
```python
def search_repository(search_input_id: str | int, repo_name: str):
    """Search for a repository using the search input.
    
    Args:
        search_input_id: The ID of the search input element
        repo_name: The name of the repository to search for
        
    Returns:
        None
        
    Examples:
        search_repository('241', '2019-nCov')
        search_repository('142', 'project-name')
    """
    click(search_input_id)
    fill(search_input_id, repo_name)
    press(search_input_id, 'Enter')
```

```python
def fork_repository_to_namespace(fork_button_id: str | int, namespace_button_id: str | int):
    """Fork a repository to a specific namespace.
    
    Args:
        fork_button_id: The ID of the fork button
        namespace_button_id: The ID of the namespace selector button
        
    Returns:
        None
        
    Examples:
        fork_repository_to_namespace('475', '415')
        fork_repository_to_namespace('fork-btn', 'personal-namespace')
    """
    click(fork_button_id)
    click(namespace_button_id)
```
