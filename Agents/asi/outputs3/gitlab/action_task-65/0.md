## Reusable Functions
```python
def navigate_to_repo_file(repo_link_id: str, file_link_id: str):
    """Navigate from homepage to a specific file in a repository.
    
    Args:
        repo_link_id: The ID of the repository link
        file_link_id: The ID of the file link
        
    Returns:
        None
        
    Examples:
        navigate_to_repo_file('617', '766')
    """
    click(repo_link_id)  # Click repository link
    click(file_link_id)  # Click file link
```

```python
def change_license_to_copyleft(edit_button_id: str, apply_license_id: str, agpl_option_id: str, commit_button_id: str):
    """Change the license to a copyleft license (AGPL v3.0).
    
    Args:
        edit_button_id: The ID of the Edit button
        apply_license_id: The ID of the "Apply a license template" button
        agpl_option_id: The ID of the AGPL v3.0 option
        commit_button_id: The ID of the Commit changes button
        
    Returns:
        None
        
    Examples:
        change_license_to_copyleft('550', '501', '517', '727')
    """
    click(edit_button_id)  # Click Edit button
    click(apply_license_id)  # Click "Apply a license template"
    click(agpl_option_id)  # Select AGPL v3.0 license
    click(commit_button_id)  # Commit the changes
```
