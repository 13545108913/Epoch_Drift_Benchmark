Task: Submit a merge request to merge {source_branch} into {target_branch} and assign {reviewer} as the reviewer
Action Trajectory:
```click({repo_item})```  # open the repository page where the branches live
```click({new_merge_request_button})```  # open the New Merge Request / Create MR form
```fill({source_branch_field}, {source_branch})
fill({target_branch_field}, {target_branch})```  # select or enter the source and target branches for the MR
```click({assignee_button})
click({reviewer_item})```  # open assignee/reviewer controls and select {reviewer} as the reviewer
```click({create_merge_request_button})
send_msg_to_user("Created merge request from {source_branch} into {target_branch} and assigned {reviewer} as reviewer.")```
