## Reusable Functions
```python
def create_milestone(project_link_id: str, milestones_tab_id: str, new_milestone_button_id: str,
                     title_field_id: str, desc_field_id: str, start_field_id: str, due_field_id: str,
                     save_button_id: str, title: str, description: str, start_date: str, end_date: str):
    """Create a milestone by navigating to a project's Milestones area, opening the new milestone form,
    filling the fields, and saving it.

    Args:
        project_link_id: ID of the project link or entry point to open the project.
        milestones_tab_id: ID of the Milestones tab or link inside the project.
        new_milestone_button_id: ID of the button/link to create a new milestone.
        title_field_id: ID of the form field for the milestone title.
        desc_field_id: ID of the form field for the milestone description.
        start_field_id: ID of the form field for the start date.
        due_field_id: ID of the form field for the due/end date.
        save_button_id: ID of the button to save/create the milestone.
        title: The milestone title text.
        description: The milestone description text.
        start_date: The milestone start date in the format used by the UI (e.g., "2023-01-16").
        end_date: The milestone end/due date in the format used by the UI (e.g., "2023-02-05").

    Returns:
        dict: A summary dict containing the title, start_date, end_date and the IDs used to create it.

    Examples:
        >>> create_milestone('283', '304', '459', '446', '483', '517', '524', '528',
                             'Sprint planning', 'Planning sprint work', '2023-02-01', '2023-02-07')
        {'title': 'Sprint planning', 'start_date': '2023-02-01', 'end_date': '2023-02-07',
         'project_link_id': '283', 'milestones_tab_id': '304', 'save_button_id': '528'}
    """
    # Step 1: navigate to the project and open the Milestones tab
    click(project_link_id)
    click(milestones_tab_id)

    # Step 2: open the new milestone form
    click(new_milestone_button_id)

    # Step 3: fill in milestone details
    fill(title_field_id, title)
    fill(desc_field_id, description)
    fill(start_field_id, start_date)
    fill(due_field_id, end_date)

    # Step 4: save the milestone
    click(save_button_id)

    return {
        "title": title,
        "start_date": start_date,
        "end_date": end_date,
        "project_link_id": project_link_id,
        "milestones_tab_id": milestones_tab_id,
        "save_button_id": save_button_id
    }
```
