Task: Update the project site's title to {title}
Action Trajectory:
```click({repo_item})```  # open the project/repository page that contains the site settings
```click({settings_button})```  # open the project or site settings where the site title can be edited
```fill({title_field}, {title})```  # enter the new site title into the title input field
```click({save_button})```  # save or publish the settings to apply the new title
```send_msg_to_user("Updated site title to {title}.")```  # confirm the update to the user
