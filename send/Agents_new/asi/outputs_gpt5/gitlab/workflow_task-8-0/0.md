Task: Set the homepage (Website) URL on my GitLab profile to {url}
Action Trajectory:
```click({user_avatar})```  # open the user menu or navigate to the profile/settings entry point
```click({edit_profile})```  # open the Edit Profile / Profile settings page
```fill({website_field}, {url})```  # enter the desired homepage/website URL into the Website/URL field
```click({save_button})```  # save or update the profile to persist the change
```send_msg_to_user("Your GitLab profile Website URL is set to {url}. Profile was successfully updated.")```  # confirm the update to the user
