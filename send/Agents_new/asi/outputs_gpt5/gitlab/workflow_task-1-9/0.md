Task: Open my latest updated issue that has keyword {keyword} in its title to check if it is closed
Action Trajectory:
```click({repo_item})```  # open the repository page that contains the issues
```click({issues_tab})```  # open the Issues tab for the repository
```fill({issues_search}, {keyword})```  # enter the keyword into the issue search/filter box to narrow titles
```click({latest_filtered_issue})```  # open the topmost result, which is the most recently updated issue matching the keyword
```send_msg_to_user("Opened issue '{issue_title}' (#{issue_number}). Status: {OPEN/CLOSED}")```  # report whether the opened issue is open or closed
