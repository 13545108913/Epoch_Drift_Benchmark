Task: Add the following users to my {repo} as {role}
Action Trajectory:
```click({repo_item})```  # open the repository page for {repo}
```click({members_tab})```  # open the Members / Access section for the repository
```click({invite_members_button})```  # open the invite/add members dialog
```fill({invite_field}, {user_list})
click({role_dropdown})
click({role_item})
click({send_invites_button})```  # enter the usernames (comma/newline-separated), choose the {role}, and send the invitations
```send_msg_to_user("Invited {user_list} to {repo} as {role}.")```  # confirm the invitations were sent and report back to the user
