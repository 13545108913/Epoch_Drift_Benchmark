Task: Invite {collaborator_account_list} as collaborator to {repo} repo
Action Trajectory:
```click({repo_item})```  # open the repository page
```click({members_tab})```  # open the Members/Access section for the repository
```click({invite_members_button})```  # open the invite members dialog
```fill({invite_field}, {collaborator_account_list}); click({invite_confirm_button})```  # enter the collaborator account names/emails (comma-separated or one-by-one) and submit the invitations
```send_msg_to_user("Invited {collaborator_account_list} to {repo}.")```  # confirm the invitations were sent
