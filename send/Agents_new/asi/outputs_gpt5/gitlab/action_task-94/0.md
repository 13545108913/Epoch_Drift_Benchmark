Reusable Functions
```python
def search_repo(search_bar_id: str | int, query: str, repo_result_id: str | int):
    """Search for a repository and open it from the results.

    Args:
        search_bar_id: ID of the search input element.
        query: Text to search for (e.g., repository name).
        repo_result_id: ID of the repository result to click.

    Returns:
        None

    Examples:
        search_repo('241', 'dotfiles', '289')
    """
    click(search_bar_id)
    fill(search_bar_id, query)
    keyboard_press("Enter")
    click(repo_result_id)
```

```python
def navigate_to_members(repo_page_id: str | int, settings_id: str | int, members_button_id: str | int):
    """Navigate from an opened repository page into its members (invite) section.

    Args:
        repo_page_id: ID to click to focus the opened repository page.
        settings_id: ID to click to open repository settings or related area.
        members_button_id: ID to click to open the members/invite panel.

    Returns:
        None

    Examples:
        navigate_to_members('395', '407', '490')
    """
    click(repo_page_id)
    click(settings_id)
    click(members_button_id)
```
