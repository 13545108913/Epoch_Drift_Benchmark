Task: Submit a merge request to merge {source_branch} into {target_branch} and assign {reviewer} as the reviewer
Action Trajectory:
```click({repo_item})```  # open the repository page that contains the branches and merge requests
```click({merge_requests_tab})```  # open the Merge Requests tab
```click({new_merge_request_button})```  # open the New Merge Request / compare branches form
```fill({source_branch_field}, {source_branch})
fill({target_branch_field}, {target_branch})```  # select or enter the source and target branches for the MR
```click({assignee_button})
click({reviewer_item})
click({create_merge_request_button})
send_msg_to_user("Created merge request from {source_branch} into {target_branch} and assigned {reviewer} as reviewer: {mr_link_or_id}")```  # assign the reviewer, create the MR, and report the created MR to the user
