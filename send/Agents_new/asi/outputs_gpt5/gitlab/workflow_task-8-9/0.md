Task: Invite {collaborator_account_list} as collaborator to {repo}
Action Trajectory:
```click({repo_item})```  # open the repository page for {repo}
```click({members_tab})```  # open the Members / Access section where collaborators are managed
```click({invite_members_button})```  # open the invite members dialog or form
```fill({invite_field}, {collaborator_account_list})
click({invite_submit_button})```  # enter the collaborator account(s) (comma-separated if multiple) and submit the invitation
```send_msg_to_user("Invited {collaborator_account_list} to {repo} as collaborator(s).")```  # confirm the invitations were sent to the user
