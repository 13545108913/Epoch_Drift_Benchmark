Task: Invite {collaborator_account_list} as collaborator to {repo} repo
Action Trajectory:
```click({repo_item})```  # open the repository page for {repo}
```click({members_tab})```  # open the Members / Access / Collaborators section
```click({invite_members_button})```  # open the invite dialog to add collaborators
```fill({invite_field}, {collaborator})
keyboard_press("Enter")
select_option({role_select}, {role})
click({send_invite_button})```  # for each collaborator in {collaborator_account_list}, enter their account, confirm (Enter), choose the role (e.g., Developer), and send the invite; repeat this sequence for every collaborator
