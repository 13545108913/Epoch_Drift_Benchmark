Task: Count the number of commits a given user made during a specified period.
Action Trajectory:
```click({search_bar})```  # focus the global/site search input so we can run a commits query
```fill({search_bar}, {commit_search_query})```  # enter a commits search query, e.g. "author:{user} committer-date:{start}..{end}" (use the period converted to a date range)
```keyboard_press("Enter")```  # execute the search
```click({commits_filter})```  # switch to the "Commits" results tab or filter so results show commit entries
```send_msg_to_user("Number of commits by {user} in {period}: {commits_count}")```  # extract the total commits count from the commits results and send it to the user
