## Reusable Functions
```python
def navigate_to_repo_settings(account_menu_id: str, repo_list_id: str, repo_item_id: str):
    """
    Navigate from the account/menu area into a specific repository's settings area.

    Args:
        account_menu_id: ID of the account or menu element to open repository list.
        repo_list_id: ID of the element that contains or lists repositories.
        repo_item_id: ID of the specific repository item to open.

    Returns:
        None

    Examples:
        navigate_to_repo_settings('527', '395', '407')
    """
    click(account_menu_id)
    click(repo_list_id)
    click(repo_item_id)


def open_collaborators_tab(settings_menu_id: str, collaborators_tab_id: str):
    """
    Open the repository settings section and switch to the collaborators/invite tab.

    Args:
        settings_menu_id: ID of the settings/menu element inside the repository.
        collaborators_tab_id: ID of the collaborators (or Manage Access/Invite) tab.

    Returns:
        None

    Examples:
        open_collaborators_tab('498', '501')
    """
    click(settings_menu_id)
    click(collaborators_tab_id)
    noop(300)


def invite_collaborators(input_field_id: str, invite_button_id: str, collaborators: list):
    """
    Add one or more collaborators by entering names/emails and submitting the invite.

    Steps:
    1. For each collaborator name/email, fill the invite input and confirm with Enter.
    2. Scroll if needed to reveal the final invite button.
    3. Click the invite/confirm button to send invitations.

    Args:
        input_field_id: ID of the invite input field where names/emails are typed.
        invite_button_id: ID of the final invite/confirm button.
        collaborators: List of collaborator names or emails to add.

    Returns:
        None

    Examples:
        invite_collaborators('490', '512', ['Abishek', 'Vinta'])
    """
    for collaborator in collaborators:
        fill(input_field_id, collaborator)
        keyboard_press("Enter")
        noop(200)
    scroll(0, 300)
    click(invite_button_id)
```
