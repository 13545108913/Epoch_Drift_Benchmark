Task: Invite {collaborator_account_list} as collaborators to {repo}
Action Trajectory:
```click({repo_item})```  # open the repository page for {repo}
```click({members_tab})```  # open the Members/Access/Collaborators section
```click({invite_members_button})```  # open the invite members dialog
```fill({invite_field}, {collaborator})
click({invite_send_button})```  # for each account in {collaborator_account_list}, enter the username/email in the invite field and click the send/invite button (repeat these two actions for each collaborator)
```send_msg_to_user("Invited {collaborator_account_list} to {repo} as collaborators.")```  # confirm the invitations were sent
