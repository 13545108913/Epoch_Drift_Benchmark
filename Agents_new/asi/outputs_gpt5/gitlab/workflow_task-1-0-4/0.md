Task: Invite {collaborator_account_list} as collaborator to {repo} repo
Action Trajectory:
```click({repo_item})```  # open the repository page for {repo}
```click({members_tab})```  # open the Members / Access / Collaborators section
```click({invite_members_button})```  # open the invite members dialog
```fill({invite_field}, {collaborator_account_list})```  # enter the collaborator usernames (comma- or newline-separated) into the invite field
```click({send_invite_button})```  # send the invitations / submit the invite dialog to add the collaborators to {repo}
