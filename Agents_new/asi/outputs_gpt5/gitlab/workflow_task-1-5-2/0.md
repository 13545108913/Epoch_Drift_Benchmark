Task: Create a new group "{name}" and add members {members}
Action Trajectory:
```click({groups_nav})```  # open the Groups section of the UI
```click({new_group_button})```  # open the "New group" / create group form
```fill({group_name_field}, {name})
fill({group_path_field}, {name})
click({create_group_button})```  # enter the group name/path and create the group
```click({members_tab})
for each member in {members}:
    fill({member_input_field}, {member})
    keyboard_press("ArrowDown")
    keyboard_press("Enter")
    click({add_member_button})```  # open Members/Invite UI and add each member via autocomplete + add action
```send_msg_to_user("Created group '{name}' and added members: {members}.")```  # confirm the group was created and members were added
