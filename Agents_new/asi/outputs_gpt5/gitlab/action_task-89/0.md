## Reusable Functions
```python
def navigate_to_repo_collaborators(repo_link_id: str | int, settings_id: str | int, collaborators_tab_id: str | int):
    """Navigate from a repository listing to its collaborators tab.

    Args:
        repo_link_id: The clickable element id for the repository link.
        settings_id: The clickable element id for the repository's Settings link.
        collaborators_tab_id: The clickable element id for the "Collaborators" or access management tab.

    Returns:
        None

    Examples:
        navigate_to_repo_collaborators('803', '395', '407')
    """
    click(repo_link_id)
    click(settings_id)
    click(collaborators_tab_id)


def add_collaborator(input_id: str | int, username: str, pre_enter_delay_ms: int, add_button_id: str | int, confirm_button_id: str | int):
    """Invite a collaborator by filling the username, submitting the entry, and confirming the addition.

    Args:
        input_id: The id of the username input field for adding collaborators.
        username: The collaborator account name to invite.
        pre_enter_delay_ms: Milliseconds to wait after filling before sending Enter (simulate debounce/search).
        add_button_id: The id of the "Add" or action button to start the invite.
        confirm_button_id: The id of the final confirm button to complete the invite.

    Returns:
        None

    Examples:
        add_collaborator('490', 'yjlou', 1000, '498', '501')
    """
    fill(input_id, username)
    noop(pre_enter_delay_ms)
    keyboard_press("Enter")
    click(add_button_id)
    click(confirm_button_id)
```
