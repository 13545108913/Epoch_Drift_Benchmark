Task: Find the customer name and email that match a given phone number.
Action Trajectory:
```click({customers_section_id})```  # open the Customers page in the admin
```fill({customer_search_field_id}, {PhoneNum})```  # enter the phone number into the customer search or filter field
```keyboard_press("Enter")```  # execute the search/filter
```click({customer_row_id})```  # open the matching customer record from the search results
```send_msg_to_user("The customer with phone number {PhoneNum} is: {customer_name} ({customer_email}).")```  # extract the customer's name and email from the detail page and send to the user
