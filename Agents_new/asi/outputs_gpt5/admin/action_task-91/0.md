## Reusable Functions
```python
def open_admin_orders(menu_link_id: str, admin_orders_url: str):
    """Open the admin orders area by interacting with the admin menu and navigating to the orders URL.

    Args:
        menu_link_id: The clickable element id for opening the admin/menu area (e.g., '70').
        admin_orders_url: The direct URL to the admin orders page.

    Returns:
        None

    Examples:
        open_admin_orders('70', 'http://dockerized-magento.local/index.php/admin/sales_order/')
    """
    click(menu_link_id)
    scroll(0, 500)
    navigate_to_admin_orders(admin_orders_url)
```

```python
def filter_orders_by_status(status_select_id: str, status_value: str, search_button_id: str):
    """Filter the orders list by a given order status value.

    Args:
        status_select_id: The select element id for the status filter dropdown (e.g., '641').
        status_value: The status option value to select (e.g., 'Complete').
        search_button_id: The id of the button to apply the filter/search (e.g., '486').

    Returns:
        None

    Examples:
        filter_orders_by_status('641', 'Complete', '486')
    """
    select_option(status_select_id, status_value)
    click(search_button_id)
    scroll(0, 500)
```

```python
def open_order_details(order_row_id: str, view_order_id: str):
    """Open a specific order from the results and navigate into its details.

    Args:
        order_row_id: The id of the order row or link in the results (e.g., '1125').
        view_order_id: The id of the 'View' or details link/button for the order (e.g., '1654').

    Returns:
        None

    Examples:
        open_order_details('1125', '1654')
    """
    click(order_row_id)
    click(view_order_id)
    scroll(0, 300)
```
