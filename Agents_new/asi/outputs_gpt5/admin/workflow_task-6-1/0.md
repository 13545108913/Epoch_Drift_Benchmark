Task: Adjust the price of a product by a specified amount (percentage or fixed amount).
Action Trajectory:
```click({catalog_products_id})```  # open the Products/Catalog page to find the product to edit
```click({product_row_id})```  # open the product's edit page (select the product row or edit button)
```fill({price_field_id}, {new_price})```  # set the price field to {new_price} (calculate {new_price} by applying the specified {amount} — percentage or fixed — to the current price before filling)
```click({save_button_id})```  # save the product changes (publish/update)
```send_msg_to_user("The price has been updated to {new_price} for product {product_identifier}.")```  # confirm the update to the user
