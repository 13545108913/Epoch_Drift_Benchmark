Task: Draft a new marketing price rule for {topic} that offers {rule} for all customers
Action Trajectory:
```click({promo_quote_section_id})```  # open the Marketing > Promotions > Cart Price Rules page
```click({add_new_rule_button_id})```  # click "Add New" to start creating a new price rule
```fill({rule_name_field_id}, {topic})
fill({rule_description_field_id}, {rule})```  # set the rule name to the {topic} and put the {rule} details in the description
```select_option({discount_type_select_id}, {discount_type})
fill({discount_amount_field_id}, {discount_amount})```  # set the discount type and amount according to the {rule} (e.g., fixed amount, percent, or free shipping)
```select_option({website_select_id}, {all_websites})
select_option({customer_groups_select_id}, {all_customer_groups})
click({save_rule_button_id})```  # apply the rule to all websites and all customer groups (all customers) and save the price rule
