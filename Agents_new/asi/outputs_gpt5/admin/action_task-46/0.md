## Reusable Functions
```python
def search_magento_global(search_field_id: str | int, query: str):
    """Perform a global search in the Magento admin header search field.

    Args:
        search_field_id: The ID of the global search input element.
        query: The search string (e.g., phone number, name, order id).

    Returns:
        None

    Examples:
        search_magento_global('56', '555-229-3326')
    """
    click(search_field_id)
    fill(search_field_id, query)
    keyboard_press("Enter")
```

```python
def open_search_result_and_focus(result_item_id: str | int, primary_scroll: int, secondary_scroll: int):
    """Click a search result item and scroll to reveal more details.

    Args:
        result_item_id: The ID of the search result element to click.
        primary_scroll: First vertical scroll offset to bring page content into view.
        secondary_scroll: Additional vertical scroll offset to reach detailed section.

    Returns:
        None

    Examples:
        open_search_result_and_focus('163', 500, 200)
    """
    click(result_item_id)
    scroll(0, primary_scroll)
    scroll(0, secondary_scroll)
```

```python
def open_customer_admin_and_filter(admin_url: str, initial_scroll: int, filter_field_id: str | int, phone_number: str, filter_button_id: str | int):
    """Navigate to the customer admin page, apply a phone filter and trigger search.

    Args:
        admin_url: URL of the Magento admin customer listing page.
        initial_scroll: Vertical scroll to move into the filter area.
        filter_field_id: The ID of the customer grid phone filter input.
        phone_number: The phone number used to filter customers.
        filter_button_id: The ID of the button that applies the filter.

    Returns:
        None

    Examples:
        open_customer_admin_and_filter(
            'http://dockerized-magento.local/index.php/admin/customer/',
            800,
            '627',
            '555-229-3326',
            '481'
        )
    """
    goto(admin_url)
    scroll(0, initial_scroll)
    fill(filter_field_id, phone_number)
    click(filter_button_id)
```
