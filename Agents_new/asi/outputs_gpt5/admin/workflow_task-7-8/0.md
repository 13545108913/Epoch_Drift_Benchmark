Task: Modify the address of order #{order_id} to {address}
Action Trajectory:
```click({orders_section_id})```  # open the Orders list/page
```fill({order_search_field_id}, {order_id})
keyboard_press("Enter")```  # search for the order by its increment/id
```click({order_row_id})```  # open the matching order from the search results
```click({edit_shipping_address_button_id})
fill({street_field_id}, {address.street1})
fill({street2_field_id}, {address.street2})
fill({city_field_id}, {address.city})
select_option({state_select_id}, {address.state})
fill({postal_code_field_id}, {address.postal_code})```  # edit the shipping address fields with the provided address components
```click({save_address_button_id})
send_msg_to_user("The shipping address for order #{order_id} has been updated to: {address}")```  # save the changes and notify the user
