```python
def modify_order_address(admin_order_url: str,
                         pre_click_id: str,
                         edit_button_id: str,
                         address_section_id: str,
                         street_field_id: str,
                         city_field_id: str,
                         state_select_id: str,
                         zipcode_field_id: str,
                         save_button_id: str,
                         street: str,
                         city: str,
                         state_value: str,
                         zipcode: str):
    """Navigate to an admin order page, open the address edit section, update address fields, and save.

    Steps:
    1) Navigate to the admin order view (optionally perform an initial click).
    2) Open edit mode and the address section.
    3) Fill street, city, state, and zipcode fields.
    4) Save the changes.

    Args:
        admin_order_url: Full URL to the admin order view page for the specific order.
        pre_click_id: ID to click before navigating (e.g., to open the admin area).
        edit_button_id: ID of the edit button on the order page.
        address_section_id: ID to open the address editing area.
        street_field_id: Field ID to fill the street address.
        city_field_id: Field ID to fill the city.
        state_select_id: Select ID to choose the state option.
        zipcode_field_id: Field ID to fill the postal code.
        save_button_id: ID of the save button to persist changes.
        street: Street address text to enter.
        city: City text to enter.
        state_value: Value or visible text to select for the state.
        zipcode: Zip or postal code text to enter.

    Returns:
        None

    Examples:
        modify_order_address(
            "http://example.local/admin/sales_order/view/order_id/123/",
            "70", "699", "581", "508", "516", "776", "849", "451",
            "789 Pine Lane", "San Francisco", "California", "94102"
        )
    """
    # Step 1: enter admin area and navigate to order view
    click(pre_click_id)
    goto(admin_order_url)

    # Step 2: open edit and address section
    click(edit_button_id)
    click(address_section_id)

    # Step 3: update address fields
    fill(street_field_id, street)
    fill(city_field_id, city)
    select_option(state_select_id, state_value)
    fill(zipcode_field_id, zipcode)

    # Step 4: save changes
    click(save_button_id)
```
